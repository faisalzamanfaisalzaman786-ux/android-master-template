# 📚 Library Hub - خودکار اپ ڈیٹ ہونے والا مستحکم مرکز
یہ ہب ہر 6 گھنٹے بعد خود ریفریش ہوتا ہے۔
## فولڈرز
- **packages/** : تازہ ترین پیکجز، پرمیشنز، سینسرز
- **backups/** : پچھلے 3 ورژنز کی بیک اپ
- **versions/** : لاگ اور ناکام پیکجز کی فہرست
- **templates/** : main.dart اور AndroidManifest.xml کے نمونے
